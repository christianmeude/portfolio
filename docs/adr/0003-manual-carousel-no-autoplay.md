# Works as a manual carousel, not a grid

The four projects live in a one-per-view snap carousel with arrows, dots, swipe, and screen-reader announcements — no autoplay. Rationale: the previous stacked grid repeated the same card shape four times and buried the proof below long scrolls; the carousel gives each project a viewport and matches the minimal-text brief. Autoplay was considered and rejected: it fights the calm world, complicates reduced-motion handling, and steals focus from readers.

## Consequences

One project per view means the slide order matters — strongest proof (Nucleus, Inea) leads. Any future fifth project must earn its slide; the carousel does not scale to a gallery.
