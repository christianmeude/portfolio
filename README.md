# Christian Meude — Portfolio

Cream-first brutalist developer portfolio. Mobile, web & systems — 2 shipped, 2 WIP, every claim links to a repo.

- **Live:** coming soon (`*.vercel.app` — URL added here after first deploy)
- **Stack:** Next.js App Router, Tailwind, GSAP, Supabase (chat route only)
- **Contact:** christianmeude17@gmail.com · [github.com/christianmeude](https://github.com/christianmeude)

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Copy `.env.example` to `.env.local` and set `GEMINI_API_KEY` to enable the generative chatbot fallback. Without a key the chatbot serves curated answers from `lib/answers.ts` only.
